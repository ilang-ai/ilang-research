## Intake

Problems with SOUL, the Source Book or the canon go through the issue forms of this repository: a [counterexample](https://github.com/ilang-ai/ilang-research/issues/new?template=counterexample.yml) or an [amendment](https://github.com/ilang-ai/ilang-research/issues/new?template=amendment.yml). The gates the canon defines run automatically ([gate/](gate/)); every submission is recorded verbatim under [records/](records/). Nothing is merged by a machine.
